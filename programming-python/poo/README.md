# Object-Oriented Programming (OOP)

This folder contains exercises, assignments, and projects developed while studying Object-Oriented Programming (OOP) with Python.

The main goal of this folder is to put into practice the concepts learned during my Software Engineering classes and improve my understanding of object-oriented software development.

## Topics

The activities in this folder cover concepts such as:

- Classes and objects
- Attributes and methods
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Object relationships

## Purpose

These activities are part of my learning journey in Software Engineering and are intended to strengthen my programming logic, problem-solving skills, and ability to design organized and reusable code.
