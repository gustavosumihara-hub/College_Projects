## Topics

The activities in this folder cover concepts such as:

- Entity-Relationship Model (ER Model)
- Entity-Relationship Diagrams (ERD)
- Entities and attributes
- Relationships
- Cardinality
- Primary and foreign keys
- Conceptual modeling
- Logical modeling
- Relational Model
- Database normalization

## Purpose

The purpose of this folder is to develop my ability to analyze real-world scenarios and transform their requirements into well-structured data models.

These activities are part of my Software Engineering studies and provide the foundation for designing and implementing relational databases.
