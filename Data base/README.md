# Databases

This folder contains exercises, assignments, and projects developed during my Database studies as part of my Software Engineering degree.

The main goal is to understand the fundamental concepts behind database systems, from data organization and modeling to the implementation and manipulation of relational databases using SQL.

Throughout these studies, I explore how databases are designed, structured, managed, and used in software applications.

## Topics

The main topics covered include:

- Database fundamentals
- Database Management Systems (DBMS)
- Types of databases
- Relational and non-relational databases
- Data models
- Entity-Relationship Model (ER Model)
- Conceptual and logical data modeling
- Relational Model
- Primary and foreign keys
- Relationships and cardinality
- Database normalization
- Relational Algebra
- SQL fundamentals
- Database creation and management
- Data manipulation and queries

## Repository Structure

### Data Modeling
Contains exercises and projects focused on designing and structuring databases, including ER models, relational models, relationships, cardinality, and normalization.

### SQL
Contains practical exercises involving the creation, manipulation, and querying of relational databases using SQL.

## Purpose

The purpose of this section is to build a solid foundation in database concepts and develop both theoretical and practical skills, from designing data models to implementing and working with functional database systems.
