# SQL and Relational Databases

This folder contains exercises, assignments, and projects developed while studying relational databases and SQL.

The main goal is to apply database concepts in practice by creating, managing, and querying relational databases.

## Topics

The activities in this folder may cover concepts such as:

- Database creation
- Tables
- Primary and foreign keys
- Data types
- INSERT, UPDATE, and DELETE
- SELECT queries
- Filtering and sorting data
- JOIN operations
- Aggregate functions
- Subqueries
- Constraints
- Database normalization
- Relational Algebra

## Purpose

The purpose of this folder is to develop practical database skills and improve my ability to design, implement, and query relational databases.

These activities complement my Data Modeling studies by transforming conceptual and logical models into functional database structures.
