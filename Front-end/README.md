# Web Development

This folder contains exercises, assignments, and projects developed while studying Web Development.

The main goal is to learn and apply the fundamental technologies used to build websites and web applications, combining structure, design, and interactivity.

## Technologies

- **HTML** — Used to structure and organize web page content.
- **CSS** — Used to style pages, create layouts, and develop responsive interfaces.
- **JavaScript** — Used to add logic, interactivity, and dynamic behavior to web pages.

## Topics

The activities and projects in this folder may cover:

- HTML structure and semantic elements
- Forms and tables
- CSS selectors and properties
- Flexbox and Grid
- Responsive Design
- User Interface (UI) fundamentals
- JavaScript fundamentals
- DOM manipulation
- Events and user interactions
- Web page development

## Purpose

The purpose of this folder is to develop my front-end development skills by applying HTML, CSS, and JavaScript to practical exercises and projects.

As I progress, this folder will include increasingly complete web applications that combine these technologies.
